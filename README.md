# 基于SpringBoot的AI智能聊天应用
## 项目简介
本项目基于SpringBoot后端框架，对接阿里百炼大模型API，实现智能对话功能。
支持用户发送文本，后端调用大模型接口返回AI回答，完成聊天交互。

## 技术栈
后端：SpringBoot 2.7.x、Maven
API：阿里百炼大模型
工具：IDEA、Git

## 项目功能
1. 用户提交对话请求
2. 后端接收请求，调用AI接口
3. 将AI返回结果返回前端展示

## 项目亮点
1. 完成第三方大模型API对接，掌握HTTP接口调用
2. 规范项目分层结构（Controller、Service）
3. 代码提交使用Git进行版本管理
